    Sync & backup

    Keep your trips the same on every phone — yours and your travel partner's — free, through your GitHub account.

    1. Create a GitHub token. It opens with only gist checked. Set Expiration to No expiration, tap Generate token, and copy it.
    2. Paste it here and tap Connect. Got a pairing code from another phone? Paste that instead.
    3. Then tap Pair another phone and paste the code into Ace Travel on your partner’s phone. It carries the key that unlocks your trips.

    Your trips are encrypted on this phone before they’re saved to a secret gist in your GitHub account, so GitHub (or anyone who finds the gist) can’t read them. The token can read and write all the gists on that account, so keep it to your own phones. Documents (passport photos, PDFs) stay on the phone they were added to.
